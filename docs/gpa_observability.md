# Gas-path fault isolation: what the measurements can see

Generated by `examples/observability_study.py` for the SGT-400 class model. Field noise (1σ): power 0.35 %, fuel_flow 0.45 %, egt 2 K, p3 0.35 %, t3 1.5 K, n_gg 0.08 %, t45 3 K, p45 0.4 %.

Faults are injected one at a time at ±1 point (efficiency) or ±1 % (flow capacity), 2000 trials each, with field noise; a trial counts when the best-matching fingerprint (health faults and single sensor biases) names the injected fault.

## Findings

- The compressor and HP turbine efficiency fingerprints are nearly parallel (similarity 0.961): both raise fuel flow and EGT together. A 1-point fault is still large against field noise, so each is named in 97 % and 97 % of single snapshots, but smaller faults will be confused more often.
- The faults the standard package isolates worst at one load are WC (59 %, most often mistaken for a n_gg sensor bias) and ηPT (69 %, mistaken for a power sensor bias). They look like an instrument drift because each moves essentially one measurement.
- Adding T45 changes little here (ηPT 71 %): with a 3 K rake uncertainty it carries little that EGT and speed do not. P45 tightens every estimate (σ ηPT 0.57 to 0.45) but does not change which faults are confused.
- A second snapshot at 60 % load with the existing instruments is what works: WC rises to 77 % and ηPT to 94 %, and every σ falls. The gas generator runs at a different corrected speed at part load, so the fingerprints rotate relative to each other and to the sensor biases. In service this is a pair of points from the same day's dispatch, which the part-load fleet monitor provides.

## Limits

- Linear, single-fault isolation on a synthetic engine; multiple simultaneous faults need the weighted least-squares estimate (`GasPathAnalysis.estimate`) and benefit from a prior.
- The T45 and P45 noise levels are assumptions for a field rake; their real values come from the instrument budget.
